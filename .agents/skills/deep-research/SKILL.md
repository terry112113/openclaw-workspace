# Deep Research

**version**: 1.0.0

**description**: 深度研究框架，通过多轮迭代搜索和信息整合完成全面研究

---

## 输入输出

### 输入（Parameters）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| topic | string | 是 | 研究主题或问题 |
| scope | string | 否 | 研究范围：brief(简短)/comprehensive(全面) |

### 输出（Returns）

| 类型 | 说明 |
|------|------|
| string | 结构化研究报告，包含关键发现、数据来源和专家观点 |

---

## 适用场景

- 需要深度研究框架的场景
- 自动化任务执行
- 信息检索和分析

---

## 依赖

- 环境要求：无
