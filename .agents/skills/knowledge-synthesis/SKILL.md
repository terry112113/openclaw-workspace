# Knowledge Synthesis

**version**: 1.0.0

**description**: 多源知识整合与综合分析，从多个文档提取信息形成统一结论

---

## 一句话描述

多源知识整合与综合分析，从多个文档提取信息形成统一结论

---

## 输入输出

### 输入（Parameters）

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|--------|
| sources | array | 是 | 知识来源列表 | ["doc1.md","doc2.md"] |
| question | string | 是 | 要回答的核心问题 | "总结项目关键风险" |

### 输出（Returns）

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 综合分析报告 | "风险1:... 风险2:..." |

---

## 适用场景

### 适用场景
+多文档综合分析
+跨领域知识整合

### 不适用场景
-单一文档处理
-实时新闻搜索

---

## 依赖

无

---

## 测试用例

```json
{
  "input": {"sources":["a.md","b.md"],"question":"关键风险"},
  "expected_output": "综合分析报告"
}
```
