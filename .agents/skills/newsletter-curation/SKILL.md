# Newsletter Curation

**version**: 1.0.0

**description**: 新闻简报制作，支持多源聚合和个性化编辑

---

## 一句话描述

新闻简报制作，支持多源聚合和个性化编辑

---

## 输入输出

### 输入（Parameters）

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|--------|
| topics | array | 是 | 关注主题列表 | ["AI","创业"] |
| style | string | 否 | 简报风格：brief/detailed | "brief" |

### 输出（Returns）

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 新闻简报内容 | "## 本周AI动态\n1. ...\n2. ..." |

---

## 适用场景

### 适用场景
+周报/月报
+信息聚合

### 不适用场景
-单一主题深度
-实时新闻

---

## 依赖

多源新闻API

---

## 测试用例

```json
{
  "input": {"topics":["AI","创业"],"style":"brief"},
  "expected_output": "新闻简报内容"
}
```
