# Planning With Files

**version**: 1.0.0

**description**: 基于文件的规划辅助，支持项目拆解和任务分解

---

## 一句话描述

基于文件的规划辅助，支持项目拆解和任务分解

---

## 输入输出

### 输入（Parameters）

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|--------|
| project_desc | string | 是 | 项目描述 | "开发一个博客系统" |
| constraints | string | 否 | 约束条件 | "2周交付，2人团队" |

### 输出（Returns）

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 任务分解和时间线 | "{'tasks':['1.设计DB','2.开发API'],'timeline':'2周'}" |

---

## 适用场景

### 适用场景
+项目规划
+任务分解

### 不适用场景
-正在进行的项目
-简单任务

---

## 依赖

无

---

## 测试用例

```json
{
  "input": {"project_desc":"开发博客系统","constraints":"2周"},
  "expected_output": "任务分解和时间线"
}
```
