# 三司会审-brainstorm Skill

## 描述
三司会审专用讨论技能，强制多方案权衡、两阶段审查、原子化输出。

## 触发词
/brainstorm 或 "开启讨论"

## 核心流程

### 阶段1：探索上下文
- 李元芳调查背景
- 魏征收集证据
- 狄仁杰记录关键约束

### 阶段2：多方案探索
**强制要求：每方至少提2-3个方案**
- 李元芳方案 + 理由
- 魏征方案 + 理由  
- 狄仁杰综合方案

### 阶段3：分段展示设计
狄仁杰分段陈述，逐段确认：
```
方案A - 优势 - 风险 - 建议
方案B - 优势 - 风险 - 建议
```

### 阶段4：双重审查
1. **AI self-review**（宋慈执行）
   - 占位符检查
   - 一致性检查
   - 范围检查
   - 歧义检查

2. **用户gate**（太上皇御览）
   - 狄仁杰呈上各方案
   - 太上皇选择或修改

### 阶段5：原子化输出
魏征制定原子化执行清单：
- 每个任务 2-5分钟
- 明确产出标准
- 交接给执行者

## 输出格式

```markdown
# 讨论主题：XXX

## 背景
-

## 方案权衡
| 方案 | 优势 | 风险 | 置信度 |
|------|------|------|--------|
| A    | ...  | ...  | 高/中/低 |

## 决策
-

## 原子化任务
1. [任务描述] (2min)
2. [任务描述] (3min)
```

## 配置
```yaml
name: 三司会审-brainstorm
description: 强化讨论技能
trigger: /brainstorm
```
