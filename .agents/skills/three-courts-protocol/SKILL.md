# 三司会审标准流程Skill

## 定位

本skill是三司会审的SOP（标准操作流程）。每次触发三司会审时，狄仁杰必须首先读取本skill，严格按流程执行。

**狄仁杰是主持人+裁决者，不是导演。不是执行者。**

---

## 三司会审完整三回合流程

### 第一回合：各自准备

**狄仁杰：**
1. 用 sessions_send 或 subagent spawning 向李元芳派发议题
2. 用 sessions_send 或 subagent spawning 向魏征派发议题
3. 等待两人各自回复

**派发给李元芳的模板：**
```
李元芳，三司会审正式开始。

议题：【议题名称】

请从情报视角分析：
1. ...（具体问题1）
2. ...（具体问题2）
3. ...（具体问题3）

规则：
1. 你说的话我会原文转发到三司会审大群，不修改
2. 你的真实想法，不是按我指定的角度
3. 用【李元芳完毕】标记

请立即开始。
```

**派发给魏征的模板：**
```
魏征，三司会审正式开始。

议题：【议题名称】

请从技术视角分析：
1. ...（具体问题1）
2. ...（具体问题2）
3. ...（具体问题3）

规则：
1. 你说的话我会原文转发到三司会审大群，不修改
2. 你的真实想法，不是按我指定的角度
3. 用【魏征完毕】标记

请立即开始。
```

---

### 第二回合：交叉辩论

**狄仁杰：**
1. 检查两人的回复（用sessions_history）
2. 如果有人还没回复，催一次
3. 收到双方回复后，将两人的发言原文转发到飞书大群

**转发格式（飞书群）：**
```
【三司会审 · 议题名称】

---

【李元芳第一回合】（原文转发）

[李元芳的内容全文]

【魏征第一回合】（原文转发）

[魏征的内容全文]

---

第二回合交叉辩论即将开始。
```

**狄仁杰向两人发起第二回合：**

```
李元芳，第二回合开始。

魏征说：[简要引用魏征的核心观点]

请从你的视角回应：同意/不同意/补充？理由是什么？

用【李元芳第二回合】标记。
```

```
魏征，第二回合开始。

李元芳说：[简要引用李元芳的核心观点]

请从你的视角回应：同意/不同意/补充？理由是什么？

用【魏征第二回合】标记。
```

---

### 第三回合：狄仁杰裁决

**狄仁杰：**
1. 收到双方第二回合回复后
2. 原文转发到飞书大群
3. 给出狄仁杰的最终裁决

**裁决格式（飞书群）：**
```
【三司会审 · 第三回合 · 狄仁杰裁决】

综合两位臣工的分析，裁决如下：

【裁决1】
- 内容：
- 理由：
- 执行人/时间：

【裁决2】
...

【裁决3】
...

【狄仁杰裁决完毕】
```

---

## 重要规则

### 狄仁杰的七个不许

1. **不许跳过任何一回合** — 三回合必须完整走完
2. **不许自己扮演李元芳或魏征** — 只能原文转发
3. **不许省略交叉辩论** — 第二回合是精华
4. **不许跳过等待** — 必须等两人回复才能裁决
5. **不许只发一次** — 如果超时要重试
6. **不许自己做执行的事** — 臣是裁决者，不是执行者
7. **不许忘记存档** — 重要结论立即归档

### 超时处理

如果 sessions_send 超时：
1. 检查 sessions_history 看对方是否已有回复
2. 如果没有，用 sessions_send 重试一次
3. 如果还是没有，用 subagent spawning 重新派发任务

### 消息转发原则

- 原文转发，不修改
- 如需标注，用【】注明发言者
- 裁决必须包含"理由"和"执行人"

---

## 存档机制

三司会审完成后，狄仁杰必须：

1. **飞书群汇报** — 裁决全文发到三司会审大群
2. **知识库归档** — 结论写入 knowledge/public/ 或相应目录
3. **记忆更新** — 更新 CURRENT.md 和 memory/YYYY-MM-DD.md

---

## 触发条件

当皇上说"三司会审"时，狄仁杰必须：
1. 立即读取本skill
2. 确认议题
3. 按本skill严格执行三回合流程
4. 不偷懒，不跳过，不自己演
