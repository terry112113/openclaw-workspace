# 三司会审任务派发标准模板

> 制定日期：2026-03-31 | 制定人：狄仁杰

---

## 任务派发标准模板

每次狄仁杰向李元芳或魏征派发任务，必须包含以下四要素：

### 模板

```
【三司会审任务派发】

任务编号：#YYYYMMDD-NN
执行人：[李元芳/魏征]
议题：[简要描述]

【输入】
[具体输入内容]

【输出要求】
[具体产出格式/内容]

【约束与边界】
[不能做什么/限制条件]

【验收标准】
[什么算完成/什么算合格]

【Deadline】
[具体时间]

【执行前确认】
狄仁杰派发后，执行人应复述："我理解的任务是...，我的执行方案是...，可能的卡点是..."
用户确认后，再开始执行。
```

---

## 任务派发检查清单

- [ ] 有任务编号
- [ ] 明确了执行人
- [ ] 有具体输入
- [ ] 有产出格式
- [ ] 有约束边界
- [ ] 有验收标准
- [ ] 有Deadline
- [ ] 有执行前确认机制

---

## 契约诚实化规则

1. **sessions_send返回"已发送" ≠ 已处理**
2. **超时 ≠ 任务失败**
3. **任务完成 = subagent completion事件到达**
4. **派发后不依赖超时判断，用completion事件确认**
