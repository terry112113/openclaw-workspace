# 🏛️ 记忆系统完善研究项目

**项目名称：** 记忆系统永不停摆  
**启动时间：** 2026-03-27  
**项目经理：** 唐王李世民  
**目标：** 设计一个永远不会忘记重要事情、永远不会静默失败的记忆系统

---

## 问题陈述

当前记忆系统存在以下问题：

1. **两套热记忆系统** — workspace-main/memory/hot-1h.md 和 memory-keeper/memory/hot-1h.md 各写各的
2. **cron写路径错误** — isolated session的相对路径解析到错误位置
3. **监控盲点** — 只检查consecutiveErrors，不检查job.enabled=false
4. **中文文件名乱码** — isolated session写中文名会变成乱码
5. **没有内存连续性保障** — 热记忆更新可能被跳过无人知道

## 核心研究问题

1. **如何确保"记忆应该写入"这个事实被验证？**
   - 不仅检查cron是否跑了，检查文件是否真的写对了位置
   - 写入后读取验证

2. **如何设计"记忆连续性"保障？**
   - 每次启动时，系统如何知道自己上一次记忆停在哪里
   - 如何检测"记忆链条断裂"

3. **如何设计"记忆的健康检查"？**
   - 热记忆超过X分钟未更新 → 自动告警
   - 记忆文件大小异常（如突然变成0字节）→ 自动恢复
   - 记忆文件乱码 → 自动重新生成

4. **如何设计"记忆不遗漏"的写入机制？**
   - 每次写入都要"写入+读取验证"
   - 验证失败自动重试
   - 3次失败后告警
