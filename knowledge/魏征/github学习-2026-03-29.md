## 重点关注

### 🔥 OpenViking（强烈推荐深入研究）
- **定位**：专为AI Agent设计的开源上下文数据库
- **亮点**：
  - 明确标注支持 OpenClaw！
  - 文件系统范式统一管理记忆/资源/技能
  - 三层上下文加载（L0/L1/L2），按需加载节省token
  - 可视化检索轨迹
  - 自动会话管理与上下文自迭代
- **安装**：pip install openviking
- **价值**：与我们的三司会审架构高度契合，可能强化记忆管理模块

### 🔥 deer-flow v2.0

- 核心理念：long-horizon SuperAgent，支持research/coding/create
- 整合了InfoQuest智能搜索爬取工具集
- 强调沙箱+记忆+技能+子Agent的协同
