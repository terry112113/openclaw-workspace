## —— 76岁男性，冠心病+CKD5期+颈动脉狭窄

> **制定者：** 魏征（中医辅助角色）  
> **制定日期：** 2026年3月29日  
> **病情摘要：** 肌酐691（ CKD5期）、LAD狭窄70%、颈动脉狭窄70-99%、高血压性心脏病、肾性贫血、低蛋白血症  
> **核心原则：** 以西医为主、中医为辅；中医方案必须与西医治疗兼容，不冲突；一切以安全为第一优先

## ⚠️ 最重要的原则：CKD5期的中医安全红线

### 🚫 CKD5期患者 **绝对禁止** 的中药/食材

| 类别 | 禁止原因 | 举例 |
|------|---------|------|
| **高钾中药** | 肾功能衰竭无法排钾，高血钾可致心律失常猝死 | 泽泻、木通（关木通含马兜铃酸）、夏枯草、龙胆草、牛膝 |
| **高磷食材** | 肾脏无法代谢磷，加重血管钙化 | 坚果、芝麻、花生、瓜子 |
| **高蛋白 heavy 补品** | 加重肾脏负担，可能引发尿毒症 | 海参、鲍鱼、蛋白粉（过量） |
| **活血化瘀猛药** | CKD5期有出血风险（贫血、血小板可能低），与抗凝药冲突 | 水蛭、虻虫、斑蝥 |
| **马兜铃酸类** | 肾毒性，可加速肾功能恶化 | 关木通、广防己、青木香、天仙藤 |
| **大剂量甘草** | 潴钠排钾，升高血压，加重心脏负担 | 炙甘草汤、甘草粉（长期大量） |
| **生冷食物** | 伤肾阳，加重水肿 | 冰品、西瓜、苦瓜、黄瓜 |
| **高嘌呤食物** | 肾脏无法代谢，加重尿毒症风险 | 动物内脏、浓汤、啤酒 |

|------|------|----------------|

## 一、倪海厦心脏病经方整理（适合该患者的筛选版）

### 1. 心脏保养基础方——倪海厦「心脏三剑客」

倪海厦认为心脏病本质是「心阳不足 + 心血瘀阻 + 脾虚痰湿」，三者共同致病：

#### ① 桂枝甘草汤（心阳不振）
```
组成：桂枝12g 炙甘草6g
功效：振奋心阳、缓急止痛
适用：心悸、心慌、胸前区闷痛（轻微）
注意：CKD5期，甘草用量减半，症状缓解即停
```

#### ② 血府逐瘀汤化裁（心血瘀阻）
```
组成：桃仁10g 红花6g 当归10g 川芎10g 赤芍15g 牛膝10g
      桔梗6g 枳壳6g 柴胡6g 生地12g 丹参15g 炙甘草3g
功效：活血化瘀、行气止痛
适用：冠心病、心绞痛、颈动脉斑块
注意：CKD5期去生地（滋腻碍肾），加黄芪15g固气
```

#### ③ 真武汤（心肾阳虚、水气凌心）
```
组成：附子6g（先煎） 茯苓20g 白芍15g 白术12g 生姜3片
功效：温阳利水、治疗心衰水肿
适用：高血压性心脏病合并心功能不全、下肢水肿
注意：附子有毒性，CKD5期必须小剂量（3-6g），先煎1小时，必须在中医师指导下使用
```

### 2. 高血压调理方——倪海厦思路

倪海厦认为高血压本质是「肝阳上亢 + 肾阳不足 + 痰湿阻络」：

#### 天麻钩藤饮简化版
```
组成：天麻10g 钩藤15g 石决明20g 栀子6g 黄芩10g
      川牛膝12g 杜仲12g 益母草15g 茯神15g 夜交藤20g
功效：平肝熄风、清热活血
适用：肝阳上亢型高血压（面红、急躁、头晕）
注意：CKD5期去栀子、黄芩（苦寒伤肾），改用桑寄生15g
```

### 3. 肾脏病经方——倪海厦思路（谨慎使用）

倪海厦对尿毒症的思路是「温阳化气、泻浊排毒」：

#### 附子理中汤合五苓散（脾肾阳虚、水湿内停）
```
组成：附子6g（先煎） 干姜6g 党参10g 白术12g 炙甘草3g
      茯苓20g 泽泻15g 猪苓10g 桂枝10g
功效：温补脾肾、利水泻浊
适用：CKD3-4期水肿、尿少、畏寒
⚠️ CKD5期（肌酐691）：此方需在肾内科中医师指导下使用
⚠️ 附子有肾毒性风险，必须先煎减毒
```

## 二、倪海厦食疗方案（针对该患者筛选版）

### 1. 心脏保养食疗

#### 山楂丹参茶（倪海厦推荐）
```
材料：山楂干5g 丹参3g 三七粉1g（冲服）
做法：山楂、丹参煮水300ml，冷却后加三七粉拌匀
用法：每日1次，晨起空腹温服（饭后30分钟更安全）
功效：活血化瘀、软化血管、降低血脂
注意：三七粉有抗凝作用，与阿司匹林同用需咨询医生
```

#### 黑木耳拌洋葱（血管清道夫）
```
材料：黑木耳（干）5g泡发 洋葱30g 橄榄油少许
做法：黑木耳焯熟，洋葱切丝，少许橄榄油、醋调味
用法：每周3次，佐餐
功效：黑木耳活血化瘀，洋葱扩张血管
```

#### 红豆桂圆粥（心血不足）
```
材料：红豆30g 桂圆肉10g 小米50g
做法：红豆先煮30分钟，加小米、桂圆煮粥
用法：每周2-3次早餐
功效：补血养心、改善肾性贫血（配合EPO使用）
注意：红豆含钾，肾功能差者少量
```

### 2. 补肾食疗（CKD5期安全版）

#### 枸杞山药粥
```
材料：枸杞子5g 山药30g（去皮切块）粳米50g
做法：煮粥，早晨服用
功效：补肾阴、健脾胃，改善低蛋白血症辅助
注意：山药含磷，适量即可，不可天天大量吃
```

#### 冬虫夏草（慎用！需医生指导）
```
用量：0.5-1g/日，隔水蒸
功效：补肺益肾、增强免疫力
⚠️ 注意：市场假货多，价格昂贵，CKD5期患者是否使用必须由肾内科医生决定
⚠️ 绝对不能替代透析或西医治疗
```

### 3. 高血压食疗

#### 芹菜粥
```
材料：芹菜连根30g 粳米50g
做法：芹菜煮水取汁，同粳米煮粥
用法：每周2-3次早餐
功效：清肝热、辅助降压
```

#### 菊花茶
```
材料：菊花3g（杭白菊）枸杞子3g
做法：热水泡5分钟
用法：每日1杯（不放糖）
功效：清肝明目、辅助降压
```

## 三、穴位保健方案（倪海厦针灸思路 + 家庭可操作性）

### 倪海厦核心穴位：四大金刚穴

倪海厦特别重视四个穴位用于心脏病的日常保健（可艾灸或按摩）：

| 穴位 | 位置 | 作用 | 操作 | 频次 |
|------|------|------|------|------|
| **内关穴** | 手腕内侧，腕横纹上2寸，两筋之间 | 宽胸理气、缓解心绞痛、调节心律 | 拇指按压，酸胀为度，每侧3分钟 | 每日2次 |
| **膻中穴** | 胸部正中线，两乳头连线中点 | 宽胸理气、治疗胸闷心悸 | 掌心轻揉，顺时针3分钟 | 每日1次 |
| **足三里** | 膝盖下3寸，胫骨外侧旁开1横指 | 健脾和胃、补气强身 | 艾灸10分钟或按摩5分钟 | 每日1次 |
| **涌泉穴** | 脚底人字纹凹陷处 | 滋阴补肾、引火归元 | 艾灸10分钟或手掌搓热 | 每晚1次 |

### 针对该患者的增强穴位

| 症状 | 配穴 | 操作 |
|------|------|------|
| 心绞痛发作时 | 立即按压内关+膻中+鸠尾 | 拇指重按，以能耐受为度，持续5分钟 |
| 颈动脉狭窄头晕 | 风池+百会+四神聪 | 手指轻敲各30下，每日2次 |
| 血压高 | 太冲+曲池 | 按压各2分钟，以酸胀为度 |
| 下肢水肿 | 阴陵泉+三阴交+太溪 | 艾灸各10分钟，每日1次 |
| 失眠 | 神门+安眠穴（风池与翳风之间） | 按压各3分钟 |
| 贫血乏力 | 血海+膈俞+足三里 | 艾灸各10分钟，隔日1次 |

### ⚠️ 针灸/按摩禁忌
- **颈动脉狭窄处绝对禁止重按、艾灸！** 可能导致斑块脱落
- 有出血倾向（血小板低、服用抗凝药）者，禁用放血疗法
- 皮肤破溃处禁止艾灸
- 饭后1小时内不做腹部按摩

## 五、紧急情况的中医应对措施

### 场景1：急性心绞痛发作

**判断：** 胸骨后压榨样疼痛，向左肩放射，伴出汗、恐惧

**立即行动：**
1. ✅ 拨打120急救
2. ✅ 立即卧床，避免活动
3. ✅ 舌下含服硝酸甘油（西药，必须备）

**中医辅助（在等待120时）：**
- 🔹 立即按压「内关穴」（双手），用拇指重按，持续5-10分钟
- 🔹 按压「膻中穴」，顺时针揉3分钟
- 🔹 针刺「鸠尾穴」（有针灸资质者），向下斜刺0.5寸
- 🔹 若患者清醒，可含服「麝香保心丸」2粒（上海和黄药业）
- 🔹 禁止：艾灸、热敷（会加快心率）、自行服用速效救心丸（对冠心病无效）

### 场景2：高血压危象（血压>180/120）

**立即行动：**
1. ✅ 拨打120
2. ✅ 卧床，床头抬高30°
3. ✅ 舌下含服卡托普利25mg（西药）

**中医辅助：**
- 🔹 按压「太冲穴」（双侧），用力向足心方向按，持续3分钟
- 🔹 按压「曲池穴」（双侧），各2分钟
- 🔹 冰敷额头（毛巾裹冰袋）10分钟
- 🔹 禁止：艾灸、热敷、剧烈按摩

### 场景3：急性心衰发作（呼吸困难、端坐呼吸、咳粉红泡沫痰）

**判断：** 躺下就喘，必须坐起来，咳白色/粉红泡沫痰

**立即行动：**
1. ✅ 拨打120
2. ✅ **端坐位**，双腿下垂（减少回心血量）
3. ✅ 吸氧（如果有制氧机）
4. ✅ 舌下含服硝酸甘油

**中医辅助：**
- 🔹 艾灸「关元穴」「气海穴」各10分钟（回阳救逆）
- 🔹 按压「内关穴」缓解症状
- 🔹 禁食任何东西，包括中药
- 🔹 禁止：任何活血化瘀药（会加重心衰）

### 场景4：低血压休克（血压<90/60，意识模糊）

**立即行动：**
1. ✅ 拨打120
2. ✅ 平卧位，抬高双腿30°
3. ✅ 检查血糖（可能是低血糖）

**中医辅助：**
- 🔹 艾灸「百会穴」（头顶），15分钟
- 🔹 艾灸「神阙穴」（肚脐），15分钟
- 🔹 红糖水（如果能吞咽）少量口服
- 🔹 禁止：按压内关（会降压）

### 场景5：跌倒/急性脑血管意外（嘴歪、半身不遂、语言不清）

**立即行动：**
1. ✅ 拨打120
2. ✅ 平卧，头侧向一边（防止误吸）
3. ✅ 检查是否有骨折
4. ✅ 不要移动患者

**中医辅助：**
- 🔹 发病24小时内：禁针灸、禁艾灸、禁按摩
- 🔹 发病24小时后：可轻柔按摩健侧肢体
- 🔹 特别注意：颈动脉狭窄>70%，头部禁止任何重手法

## 七、与西医治疗的配合原则

### 中药与西药的相互作用警示

| 西药 | 中药冲突 | 后果 | 处理 |
|------|---------|------|------|
| 华法林 | 丹参、三七、红花、桃仁 | 抗凝增强，出血风险↑ | 禁用或严格减量 |
| 阿司匹林 | 川芎、当归（大量） | 出血风险↑ | 监测出血倾向 |
| 地高辛 | 蟾酥、附子 | 心律失常↑ | 禁止同用 |
| 利尿剂（呋塞米） | 甘草（大剂量） | 低血钾加重 | 甘草<3g/日 |
| 普利/沙坦类降压药 | 附子（大量） | 血压波动大 | 慎用附子 |
| EPO（促红素） | 红参（大量） | 血压升高↑ | 禁用红参 |

### 安全的配合方式
- ⏰ 中药与西药**间隔2小时**服用
- 📋 任何中药开始前，**必须告知肾内科/心内科医生**
- 📊 定期复查：每2周查一次肾功能和电解质（K+、Na+、Cl-、P）
- 📝 建立中药使用记录本：记录日期、药物、反应
