# 公共知识库 - 总索引

> 最后更新：2026-03-31

## 目录结构

```
knowledge/
├── public/              # 三司共享知识
│   ├── research/        # 研究报告
│   ├── operations/       # 运营文档
│   ├── lessons/         # 复盘归档
│   └── archive/         # 历史归档（只读）
├── di/                  # 狄仁杰专属
├── shensi/              # 李元芳专属
├── wei/                 # 魏征专属
└── audit/              # 审计日志
```

## 入库标准

每个文件必须包含：
1. **一句话核心**（这文件讲什么）
2. **来源标注**（从哪学来）
3. **行动建议**（这个知识怎么用）
4. **有效期/更新日期**

## 文件命名规范

```
YYYY-MM-DD-主题-贡献者.md
```

## 标签规范

文件顶部添加：
```
tags: [标签1, 标签2, ...]
```

## 目录索引

| 目录 | 说明 | 权限 |
|------|------|------|
| public/ | 三司共享知识 | 全员可读写 |
| di/ | 狄仁杰专属 | 本人可写 |
| shensi/ | 李元芳专属 | 本人可写 |
| wei/ | 魏征专属 | 本人可写 |
| audit/ | 审计日志 | 全员只读 |
| public/archive/ | 历史归档 | 只读，不可修改 |

## 核心原则

**knowledge/ = 三司的共同记忆**

- 不是仓库存垃圾，是工具箱
- 用才是最好的维护
- 不是人找知识，而是知识主动找人
