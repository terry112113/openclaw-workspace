# 唐王知识库 (workspace-main/knowledge/)

> 朕（唐王李世民）的战略知识库
> 5大臣+记忆管家学习的最终沉淀地

## 目录结构

```
workspace-main/knowledge/
├── strategic/           ← 战略级洞察（系统架构/大政方针）
├── lessons/             ← 失败教训+踩坑记录
└── minister-reports/    ← 5大臣汇报汇总
```

## 知识流转规则

```
房玄龄/杜如晦/程咬金/长孙无忌/李靖
         ↓ 写入各自 knowledge/
                ↓ 记忆管家每2小时同步到本目录
                       ↓ 唐王（朕）按需查阅
```

## 入库标准
- 有战略价值的洞察 → strategic/
- 系统性失败教训 → lessons/
- 大臣汇报摘要 → minister-reports/
- 临时文件不入库

## 文件命名
`{日期}-{来源}-{主题}.md`
