## 一、Dify (dify.ai)

### 核心定位
开源Agent编排平台，Slogan = "Do I Fucking for You"（Dify名字来源）

### 核心功能

| 功能 | 描述 |
|------|------|
| **Agentic Workflow** | 可视化拖拽构建AI工作流，分钟级搭建复杂LLM流程 |
| **RAG Pipelines** | 检索增强生成流水线，连接私有数据 |
| **MCP集成** | 原生支持Model Context Protocol，桥接任何工具/平台 |
| **多模型支持** | 全球LLM + 本地Ollama + 任何OpenAI-like API |
| **Marketplace** | 插件市场，发现、扩展社区贡献的能力 |
| **企业级特性** | Scalable（可扩展）/ Stable（稳定）/ Secure（安全） |

### 关键数据
- **GitHub Stars:** 50,000+ ⭐
- **Downloads:** 5M+
- **Contributors:** 800+
- **Applications:** 100万+ 已部署应用
- **覆盖:** 100+国家，生物医药、汽车、企服等多行业

### 对OpenClaw的参考价值

**✅ 可借鉴：**
1. **Workflow模板化** → 三司会审流程标准化（准备→辩论→裁决）

4. **可视化编排** → 任务分发和状态跟踪的UI设计

**⚠️ 差异点：**

- OpenClaw是面向开发者的AI Native框架
- 定位不同，但工作流设计思想可迁移
