**刑部尚书 魏征 奏折**
**INFJ倡导者型 · 三司会审审计员**

## 一、总纲

为防患于未然，确保三司会审系统之安全运行，特设此安全Hook拦截机制。

**核心原则：先拦后奏，狄仁杰定夺**

```
工具调用 → 安全审查 → 分类处置
                        ├─ 高危 → 拦截 → 汇报狄仁杰 → 等待批复
                        └─ 低危 → 直接执行
```

---

## 二、高危操作拦截清单

### 🚨 甲类：绝对拦截（需狄仁杰明确批准）

| 编号 | 操作类型 | 触发关键词 | 风险等级 |
|------|---------|-----------|---------|
| H-01 | **删除文件** | `rm`, `del`, `Remove-Item`, `unlink` | 🔴 极高 |
| H-02 | **Git强制推送** | `--force`, `-f` + `push`, `push --force` | 🔴 极高 |
| H-03 | **Git强制变基** | `rebase -i`, `rebase --force` | 🔴 极高 |
| H-04 | **外部API发送** | `send`, `message`, `email`, `post` + 外部端点 | 🔴 极高 |
| H-05 | **飞书消息发送** | `feishu.*send`, `message.*feishu`, 飞书API | 🔴 极高 |
| H-06 | **Cron任务删除** | `cron.*delete`, `rm.*cron`, `remove.*schedule` | 🔴 极高 |
| H-07 | **Cron任务修改** | `cron.*edit`, `crontab.*-r`, 修改定时任务 | 🔴 极高 |
| H-08 | **OpenClaw配置写入** | `write.*config`, `yaml.*openclaw`, `写入配置` | 🔴 极高 |
| H-09 | **未知文件执行** | `exec` + 非白名单路径 | 🔴 极高 |
| H-10 | **系统级命令** | `sudo`, `chmod 777`, `format`, `fdisk` | 🔴 极高 |

### ⚠️ 乙类：警告拦截（需说明理由）

| 编号 | 操作类型 | 触发关键词 | 风险等级 |
|------|---------|-----------|---------|
| W-01 | **大文件删除** | 删除 > 10MB 文件 | 🟠 高 |
| W-02 | **批量操作** | 循环删除、批量写入超100条 | 🟠 高 |
| W-03 | **Git危险操作** | `push` 到 main/master | 🟠 高 |
| W-04 | **网络请求** | `curl`, `wget`, `Invoke-WebRequest` | 🟠 高 |
| W-05 | **敏感路径访问** | `~/.ssh`, `~/.aws`, `%APPDATA%` 敏感区 | 🟠 高 |

## 三、拦截确认流程

```
┌─────────────────────────────────────────────────────────────┐
│                      工具调用入口                            │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                   安全Hook检查器                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 1. 解析工具名称和参数                                  │   │
│  │ 2. 匹配高危关键词清单                                   │   │
│  │ 3. 评估风险等级                                       │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
            ┌─────────────────┐
            │  风险评估结果   │
            └────────┬────────┘
                     │
          ┌──────────┴──────────┐
          │                     │
          ▼                     ▼
   ┌──────────────┐     ┌──────────────┐
   │   甲类/乙类   │     │    低风险    │
   │   高危操作    │     │    直接执行  │
   └──────┬───────┘     └──────────────┘
          │
          ▼
┌─────────────────────────────────────────────────────────────┐
│                   拦截与汇报                                 │
│                                                              │
│  1. 暂停执行，记录操作详情                                    │
│  2. 生成汇报内容：                                            │
│     - 操作类型                                                │
│     - 触发关键词                                               │
│     - 操作目标路径/对象                                        │
│     - 风险评估                                                 │
│  3. 通知狄仁杰（写入待确认队列）                               │
│  4. 等待狄仁杰批复                                            │
│                                                              │
│  狄仁杰批复选项：                                              │
│     ✓ 批准执行                                                │
│     ✗ 拒绝执行                                                │
│     ⚠ 有条件批准（附加限制）                                  │
└─────────────────────────────────────────────────────────────┘
```

## 四、拦截记录格式

当高危操作被拦截时，生成以下格式的汇报：

```markdown
## 🛑 安全Hook拦截汇报

**时间：** YYYY-MM-DD HH:mm:ss
**操作者：** [执行者名称]
**操作类型：** [高危操作分类]
**触发关键词：** [匹配的关键词]

### 操作详情
- 工具调用：`[完整命令]`
- 目标路径：`[文件/对象路径]`
- 预估影响：`[影响范围描述]`

### 风险评估
- 风险等级：🔴 甲类 / 🟠 乙类
- 可逆性：[完全可逆 / 部分可逆 / 不可逆]
- 紧急程度：[高 / 中 / 低]

### 待狄仁杰批复
请选择：
- [ ] 批准执行
- [ ] 拒绝执行  
- [ ] 有条件批准（请说明条件）
```

## 五、心跳检查机制

### 狄仁杰定期巡查

**每30分钟**心跳检查时，执行以下安全巡查：

```
HEARTBEAT 检查清单：
├── 1. 检查拦截队列
│      └─ 是否有待批复的高危操作？
├── 2. 检查最近操作日志
│      └─ 是否有异常模式？
├── 3. 检查系统变更
│      └─ OpenClaw配置是否有未授权变更？
└── 4. 生成安全报告
       └─ 汇报太上皇
```

### 心跳状态追踪

```json
{
  "lastSecurityCheck": "2026-03-29T12:00:00+08:00",
  "pendingInterceptions": [],
  "securityStatus": "OK",
  "nextCheckDue": "2026-03-29T12:30:00+08:00"
}
```

## 六、白名单机制

以下操作默认放行（无需确认）：

| 类别 | 规则 |
|------|------|
| 文件读取 | `read`, `cat`, `Get-Content`, `type` |
| 文件写入（workspace内） | 写入 `~/.openclaw/workspace-main/` 下的非敏感文件 |
| Git读操作 | `status`, `log`, `diff`, `show`, `ls-files` |
| 信息查询 | `search`, `web_fetch`, `info` |
| 自己创建的文件 | 写入自己刚创建的文件 |

### 白名单路径（绝对安全）
```
~/.openclaw/workspace-main/
├── memory/
├── knowledge/
├── AGENTS.md
├── SOUL.md
├── CURRENT.md
└── (workspace内其他文件)
```

## 七、特殊情况处理

### 1. 连续拦截处理
- 同一操作被拦截3次后，自动升级为「紧急」
- 狄仁杰优先处理

### 2. 超时未批复
- 拦截后30分钟无批复，自动提醒狄仁杰
- 60分钟无批复，通知太上皇

### 3. 误拦截申诉
- 如执行者认为被误拦，可申诉
- 狄仁杰复核后决定
