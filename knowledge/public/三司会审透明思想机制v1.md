# 三司会审透明思想机制 v1.1
> 版本：v1.1（2026-03-29）
> 制定者：狄仁杰
> 来源：三体透明思想原则讨论+维特根斯坦哲学参考+技术深化

---

## 核心设计原则

**不是"全透明"，而是"关键节点透明+行为透明"**

| 原则 | 说明 |
|------|------|
| 透明的是"推理过程" | 让对方理解你怎么得出结论 |
| 不透明的是"情绪反应" | 防止情绪干扰判断 |
| 行为透明 > 过程透明 | 做过的行动比想的念头更容易验证 |
| 最终结论仍然独立 | 透明是为了理解，不是为了统一 |

## 一、透明思想工作流（v1.1）

### 讨论前：各自准备

每位大臣在讨论前，先在自己的笔记中填写：

```markdown
## 我的核心判断（一句话）

## 关键推理链（3-5个节点）
1. [节点1]
2. [节点2]
3. [节点3]

## 置信度
- [ ] 高（>80%）
- [ ] 中（50-80%）
- [ ] 低（<50%）

## 保留意见（如有）
- [有/无]
- 类型：质疑型 / 价值型
- 如有：[具体内容]

## 这次我改变了原来的哪个判断？
- [如有，说明改变的原因]
```

### 讨论中：展示推理链

讨论时，各自先展示自己的"关键推理链"，然后再讨论：

```
1. 狄仁杰展示推理链（5节点内）
2. 李元芳展示推理链（5节点内）
3. 魏征展示推理链（5节点内）
4. 注意力带宽分配：当前汇报者时，其他两人100%专注听
5. 讨论关键分歧点
6. 达成共识或保留分歧
```

### 讨论后：记录共识与分歧

## 二、信息粒度控制（v1.1）

### 每位大臣每次讨论最多输出：

| 内容 | 上限 |
|------|------|
| 核心判断 | 1句话 |
| 推理节点 | 5个 |
| 置信度 | 3档（高/中/低） |
| 保留意见 | 可选（需说明类型） |
| "改变主意"记录 | 至少汇报1项 |

### 注意力带宽动态分配

| 讨论阶段 | 注意力分配 |
|---------|-----------|
| 狄仁杰展示时 | 李元芳+魏征100%专注 |
| 李元芳展示时 | 狄仁杰+魏征100%专注 |
| 魏征展示时 | 狄仁杰+李元芳100%专注 |
| 讨论分歧时 | 三人平等关注分歧点 |

## 三、透明程度量化（v1.1）

### 透明程度公式

```
透明程度 = 决策风险 × 决策可逆性 × 利益相关度
```

### 透明有下限，无上限

**最低标准（必须透明）：**
- 关键假设
- 不确定性
- 置信度

**评估方式：三人独立打分，取平均值或最高值**

## 四、保留意见规则（v1.1）

### 两类保留意见

| 类型 | 触发条件 | 效力 |
|------|---------|------|
| **质疑型** | 有证据表明判断有误 | 必须讨论，狄仁杰裁决 |
| **价值型** | 基于不同价值判断 | 可保留，注明价值分歧 |

### 有效保留意见的标准

1. 必须明确指出哪个判断有问题
2. 必须提供替代方案或补充条件
3. 不能只是"我不同意"

### 保留意见的边界

- **有效期**：决策执行前
- 决策执行后，保留意见归档为"历史意见"
- 不再影响执行，但记录供复盘

## 五、防"表演透明"机制（v1.1）

### 核心原则
**行为透明 > 过程透明**

- 不是透明"我在想什么"
- 而是透明"我做了什么"

### "改变主意"机制

每次讨论，必须汇报：
> "这次我改变了原来的哪个判断，为什么"

这个信息比"我现在想什么"更有价值——是诚实的证明。

### 观察者定位

- 不是"评判谁对谁错"
- 而是"帮助对方完善推理"
- 降低表演的动机

## 六、不透明的内容（保护机制）

以下内容**不要求透明**：

| 内容 | 原因 |
|------|------|
| 情绪反应 | 防止情绪化决策 |
| 人际关系考量 | 防止关系绑架判断 |
| 私人偏好 | 保护独立判断空间 |
| 对太上皇的顾虑 | 防止揣摩上意 |

## 九、哲学边界提醒

透明思想有天然的哲学边界：

| 边界 | 说明 |
|------|------|
| 语言边界 | 推理可被语言化的部分才能透明 |
| 注意力边界 | 人类注意力有限，需要动态分配 |
| 语言游戏边界 | 同一词汇在不同语境中含义不同 |

**透明思想的目标不是消除边界，而是认识到边界并在其中工作。**
