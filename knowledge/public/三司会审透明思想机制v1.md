# 三司会审透明思想机制 v1.0
> 版本：v1.0（2026-03-29）
> 制定：狄仁杰
> 来源：三体透明思想原则讨论

---

## 一、核心设计原则

**不是"全透明"，而是"关键节点透明"**

| 原则 | 说明 |
|------|------|
| 透明的是"推理过程" | 让对方理解你怎么得出结论 |
| 不透明的是"情绪反应" | 防止情绪干扰判断 |
| 最终结论仍然独立 | 透明 ≠ 必须一致 |

---

## 二、透明思想工作流（初版）

### 讨论前：各自准备

每位大臣在讨论前，先在自己的笔记中填写：

```markdown
## 我的核心判断（一句话）

## 关键推理链（3-5个节点）
1. [节点1]
2. [节点2]
3. [节点3]

## 置信度
- [ ] 高（>80%）
- [ ] 中（50-80%）
- [ ] 低（<50%）

## 保留意见（如有）
- [有/无]
- 如有，说明：[...]
```

### 讨论中：展示推理链

讨论时，各自先展示自己的"关键推理链"，然后再讨论。

```
1. 狄仁杰展示推理链
2. 李元芳展示推理链
3. 魏征展示推理链
4. 讨论关键分歧点
5. 达成共识或保留分歧
```

### 讨论后：记录共识与分歧

---

## 三、信息粒度控制

防止认知过载，采用"关键节点"模式：

### 每位大臣每次讨论最多输出：

| 内容 | 上限 |
|------|------|
| 核心判断 | 1句话 |
| 推理节点 | 5个 |
| 置信度 | 3档（高/中/低） |
| 保留意见 | 可选 |

---

## 四、不透明的内容（保护机制）

以下内容**不要求透明**：

| 内容 | 原因 |
|------|------|
| 情绪反应 | 防止情绪化决策 |
| 人际关系考量 | 防止关系绑架判断 |
| 私人偏好 | 保护独立判断空间 |
| 对太上皇的顾虑 | 防止揣摩上意 |

---

## 五、与DUTIES.md的衔接

| 机制 | 关系 |
|------|------|
| 透明思想 | 辅助3轮讨论的工具 |
| DUTIES.md | 职责边界的法律文件 |
| 安全Hook | 操作的防火墙 |

**透明思想不是替代DUTIES，而是让DUTIES的3轮讨论更高效。**
