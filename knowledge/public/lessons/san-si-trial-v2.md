# 三司会审V2标准流程
> 创建时间：2026-03-30
> 适用范围：所有三司会审讨论议题
> 维护人：狄仁杰/李元芳/魏征

---

## 一、核心原则

**人主刀辅：工具是御史的刀，不是御史的主人。**

---

## 二、六步会审法

| 步骤 | 内容 | 负责人 |
|------|------|--------|
| 第一步【立案】 | 狄仁杰明确定义问题，不是泛泛而谈 | 狄仁杰 |
| 第二步【情报】 | 李元芳外部视角：竞品/数据/案例 | 李元芳 |
| 第三步【技术】 | 魏征可行性：技术上能否实现？风险点？ | 魏征 |
| 第四步【碰撞】 | 李元芳vs魏征交叉质疑，互相辩驳 | 李元芳+魏征 |
| 第五步【裁判】 | 狄仁杰拍板：做还是不做？谁来做？ | 狄仁杰 |
| 第六步【存档】 | 写入知识库，@责任人跟踪 | 全体 |

---

## 三、辩论规范

### 发言顺序
1. 李元芳发布情报方案
2. 魏征发布技术方案
3. 李元芳反驳魏征
4. 魏征反驳李元芳
5. 如需第三轮，各自发布最终陈词

### 辩论格式
```
[李元芳-方案名] 详细方案内容
[李元芳-反驳] 针对对方方案的具体反驳
[李元芳-最终陈词] 一句话总结核心观点
```

### 时间盒
- 每个议题辩论不超过3回合
- 超时由狄仁杰强制裁决

---

## 四、结论落地机制

### 决策格式（统一）
```
[决议] 选择方案X，原因Y
[任务] 魏征负责X，李元芳负责Y
[截止] YYYY-MM-DD HH:MM
[checkpoint] 检查点说明
```

### 追踪表（Bitable）
| 议题 | 决议 | 责任人 | 截止 | 状态 |
|------|------|--------|------|------|

---

## 五、工具支撑

| 工具 | 用途 |
|------|------|
| 飞书大群 | 实时辩论，皇上可见 |
| 飞书文档 | 议题记录+决策存档 |
| 飞书Bitable | 任务追踪+状态管理 |
| Cron | 自动推进+检查节点 |
| 知识库 | 历史决议召回 |

---

## 六、议题分级

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| P0 | 皇上急旨 | 立即停止一切，优先处理 |
| P1 | 三司共审 | 按六步法，严格执行 |
| P2 | 单人研究 | 分配给对应Agent，结果汇报 |
| P3 | 知识积累 | 各自学习，不占用会审时间 |

---

## 七、辩论伦理

1. **有据可循**：每个观点需要数据/案例支撑
2. **有异必驳**：不同意的观点必须反驳，不能沉默
3. **有断则行**：狄仁杰裁决后立即执行
4. **有过则记**：错误决策写入mistakes.md
