# 三司会审决议：Ollama安全漏洞隐患检测

> 日期：2026-04-01 | 裁决人：狄仁杰

---

## 核心判断

**本地≠安全。** 本地只意味着攻击面从"互联网"变成"本机所有进程"。

---

## 隐患清单

| 类别 | 风险 |
|------|------|
| 模型能力 | 幻觉加剧，20B vs 云端大厂差距 |
| 架构 | 单点故障，无SLA兜底 |
| 安全 | Ollama默认无认证，端口暴露 |
| 数据 | Prompt留存日志，上下文交叉污染 |
| 模型 | 权重投毒风险，无SHA256校验 |

---

## 立即执行（魏征主导）

| 措施 | 优先级 | 期限 |
|------|--------|------|
| 模型文件SHA256校验 | P0 | 今日 |
| 防火墙规则（阻止外部访问11434） | P0 | 今日 |
| 资源监控（CPU/内存阈值） | P1 | 本周 |
| Ollama日志审查+清理 | P1 | 本周 |
| 定期重启Ollama清空上下文 | P1 | 本周 |
| 输入过滤层 | P2 | 长期 |

---

## 降级方案

保留云端API作为降级方案，Ollama挂了切回MiniMax API。

---

*本决议经三司会审三回合辩论，狄仁杰裁决生效*
