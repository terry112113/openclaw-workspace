## 三、MCP（Model Context Protocol）生态现状

### 为什么重要
> MCP = AI领域的"LSP"（语言服务器协议）。一次编写，任何MCP兼容AI客户端都能用。

### 生态现状（截至2026年3月）
| 厂商 | 支持情况 |
|------|----------|
| **Anthropic** | 原始发明者，MCP生态最完善 |
| **OpenAI** | 已在ChatGPT Developer Mode中支持MCP，提供完整工具调用+写入 |
| **Microsoft** | 支持MCP，发布了Playwright-MCP（浏览器自动化） |
| **Google** | Vertex AI集成中 |

### MCP实用价值
- AI助手直接访问CRM、分析平台、CMS、广告工具
- 消除"导出-粘贴"的手动工作流
- 开发者通过Responses API接入MCP服务器
- 参考：developers.openai.com/api/docs/guides/tools-connectors-mcp

## 四、AI编程工具生态（2026年3月横向对比）

### 三强格局：Claude Code / Cursor / GitHub Copilot

| 维度 | Claude Code | Cursor | GitHub Copilot |
|------|------------|--------|----------------|
| **最佳场景** | 多文件推理任务 | 集成日常开发 | GitHub平台工作流 |
| **免费选项** | Codex CLI（开源） | Cursor Free | Copilot Free（2000次补全） |
| **Pro定价** | $17/月 | Cursor Pro+ $60/月 | Copilot Pro $10/月 |
| **CLI工具** | ✅ 最强 | ❌ 需换编辑器 | ✅ |
| **代理能力** | 深度代理编码 | 有限 | Agent模式（VS Code） |
| **多工具组合** | 常见：Claude Code复杂重构 + Copilot日常编辑 | — | — |

### 性价比分析（来源：NxCode）
- **最佳价值**：GitHub Copilot Pro $10/月（300个高级请求 + 编码代理 + Claude Opus 4.6）
- **免费真可用**：Bolt.new 1M tokens/月、Copilot Free 2000次补全、Codex CLI
- **$200/月层级**（Cursor Ultra / Claude Code Max 20x / Windsurf Max / ChatGPT Pro）：仅当你把AI编程作为主要生产力杠杆时才值得

### Cursor Composer 2 专项升级
- 14%编码能力提升 vs 通用模型
- specialized code models 成为实证正确的代码任务默认选项
